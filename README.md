# Floppa AI

Бесплатная нейросеть для общения, помощи с кодом, учёбы и повседневных задач. Пет-проект без вложений и коммерческой цели.

## Что умеет
- Общение с нейросетью в реальном времени
- Гостевой режим — без регистрации, с лимитом
- Вход через Google или по email/паролю
- Сохранение истории чатов
- Прикрепление файлов и изображений
- Markdown-рендер (код, цитаты, таблицы)
- Тёмная тема
- Кнопки под ответом: копировать, перегенерировать, скачать, лайк

## Стек
- **Фронтенд**: HTML, CSS, JavaScript
- **Бэкенд**: PHP 8.4
- **База данных**: MySQL
- **Нейросеть**: Google Gemini API
- **Авторизация**: Google Sign-In

## Что в репозитории
- `index.php` — основной файл (фронтенд + API)
- `config.php` — настройки (ключи, база данных)
- `google_auth.php` — Google OAuth

## Установка
1. Клонируй репозиторий
2. Настрой `config.php` под свой хостинг и API-ключи
3. Залей файлы на хостинг
4. Импортируй SQL-дамп в MySQL
5. Готово
